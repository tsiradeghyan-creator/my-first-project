# Frameworks: Tigran (line producer)
Built from S001.

1. **First read of a script** *(unnamed)*: days, cost drivers, cost per day, money vs. script. Sources: S001.
2. **Comparable pricing** *(unnamed)*: same kind of house, cars, locations, stars, director and writer give the same order of price. Sources: S001.
3. **The 1 percent question** *(unnamed)*: ask a contact exactly what you need from their knowledge. "քեզ պետք է իր ինֆորմացիայի 1%-ը" (S001)
4. **Daily cost report** *(unnamed)*: every department reports every day. Sources: S001.
5. **Second director's time plan** *(unnamed)*: call time, travel, staging, meals, tents, documents ready per breakdown. Sources: S001.
6. **Early warning** *(unnamed)*: spending on set that people say "is not a cost" is a future bill; react at once. Sources: S001.
Tools that run these numbers: director-desk `plan.py` (day breakdown, attendance), `production.py` (Կազմ, Ծախսեր, Գնացուցակ), `plan.py report finance|payroll|progress`.
