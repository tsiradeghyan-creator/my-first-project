## 🤖 Auto-Response Tool Setup

### Recommended: ManyChat
- Instagram-native integration
- Keyword triggers
- Sequence flows (escalation: cold lead → warm → hot)
- Tag leads automatically
- $0-30/month based on volume

### Alternative: Tellie
- Simpler interface
- Free tier covers ~1,000 DMs/month

### Setup steps
1. Connect Instagram Business / Creator account
2. Create keyword triggers (one per CTA above)
3. Build response flows (use templates above)
4. Tag respondents by keyword (e.g., "hot lead" for ՆԱԽԱԳԻԾ)
5. Set 24-hour follow-up rule for cold respondents
6. Monthly review of conversion funnel

## 📊 DM Funnel Stages

```
Stage 1 — Cold engagement (any keyword)
    ↓ (auto-response sent)
Stage 2 — Engaged (replied to auto-response)
    ↓ (manual reply by team)
Stage 3 — Qualified (booked call OR provided detailed answer)
    ↓ (proposal sent)
Stage 4 — Lead (in negotiation)
    ↓
Stage 5 — Client (signed contract)
```

### Conversion targets
- Stage 1 → 2: 30-50%
- Stage 2 → 3: 10-25%
- Stage 3 → 4: 30-50%
- Stage 4 → 5: 25-50%

### Overall: 1-3% of Stage 1 → Stage 5 (industry standard)

---

## ⏱️ Response Time SLAs

- **First auto-response**: < 1 minute (automated)
- **Manual follow-up**: < 24 hours weekdays, < 48 hours weekends
- **Hot lead (ՆԱԽԱԳԻԾ / ԲԱՑ)**: < 4 hours weekdays
- **Cold (ՍՑԵՆԱՐ / 47 / general)**: < 24 hours

Faster response = higher conversion (10x improvement <1hr vs >24hr industry-wide).

---

## 🗣️ Voice & Tone in DMs

### Default mode
- Professional, but warm
- Use «մենք» (agency) primarily, switch to «ես» when personal touch helps
- Armenian primary, English/Russian only if respondent uses them
- Emojis: max 2 per message (🎬 + 1 other)
- No exclamation overload

### Adjustments
- Cold lead: more polished, brand-forward
- Warm lead: more personal, founder voice
- Hot lead: direct, business, scope-focused

---

## 🚫 DM Anti-Patterns

❌ Auto-respond and never follow up manually
❌ Same auto-response for all keywords (defeats purpose)
❌ Send PDF without context («Here's the PDF» alone)
❌ Push for sale in first message (cold ⇒ warm first)
❌ Ignore non-keyword messages (leaves community feeling)
❌ Use bot-obvious language («This is an automated message»)
❌ Promise something undeliverable («24-hour custom analysis»)
❌ Mass-DM unsolicited (spam, against Instagram TOS)

---

## 📝 Pre-Flight Checklist (before deploying any DM CTA)

- ☐ The promised deliverable EXISTS (PDF / link / file ready)
- ☐ Auto-response is set up (or manual reply within 1hr possible)
- ☐ Template language aligns with brand voice
- ☐ Follow-up flow planned (Stage 2)
- ☐ Tracking pixel / UTM in any external links
- ☐ Conversion goal explicit (what's Stage 3 for this lead?)

Without all ☐: don't deploy the CTA.
