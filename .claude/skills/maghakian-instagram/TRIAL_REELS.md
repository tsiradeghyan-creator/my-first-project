## What Are Trial Reels?

Trial Reels = Instagram feature ա, որով reel-ը **publish-ից առաջ test է լինում միայն non-follower-ների վրա**։ Քո existing 989 follower-ները չեն տեսնում, քանի դեռ դու չես հաստատել «Share to Everyone»։

## 🔑 Why This Is Critical for Maghakian

- Account-ի reach-to-follower ratio = 5,260% (top reel 87.2K / 989 followers = 88x)
- Հանդիսատեսի 99% non-follower է → Trial Reels-ը **literally optimizes for your exact growth profile**
- Bad reel = no damage to follower-feed (no signal that you posted weak content)
- Good reel performance = publish to everyone with confidence

## ⚙️ How to Publish a Trial Reel

1. Create reel as usual
2. Before publishing, **toggle «Trial»** ON (next to «Share to Everyone»)
3. Publish — only non-followers see it
4. **Wait 24-72 hours** for performance data
5. Check Insights: if metrics good → tap «Share to Everyone»

- Update PROJECT_LIBRARY with «what worked» per project

## 🚫 Anti-Patterns

❌ Publishing Trial Reel and then giving up after 6 hours — needs 24-72h to settle
❌ Sharing-to-all even if Trial showed weak metrics (rationalizing «my followers will like it») — they probably won't either
❌ Testing 5 reels same week — sample size for each blurs (test 1-2/week max)
❌ Using Trial Reels for time-sensitive content (premiere announcements, etc.)
❌ Trial Reel without distinct hook from existing content (you're testing the same variable as before — wasted attempt)

## ✅ Pre-Trial Publish Checklist

- ☐ Hook is **distinct** from recent content (testing variable is clear)
- ☐ Reel is 100% finished (no «I'll improve later» mindset)
- ☐ Caption + hashtags + CTA all complete
- ☐ Schedule allows 24-72h before need to use this content elsewhere
- ☐ Tracking sheet for results (see METRICS.md)
