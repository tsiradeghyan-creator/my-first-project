## 📊 Carousel-Specific Metrics (NEW 2026)

> Per ALGORITHM_2026.md: Instagram tracks carousels slide-by-slide։ Critical metrics.

| Metric | Stop signal | Healthy | Excellent |
|--------|-------------|---------|-----------|
| Swipe-through to slide 2 | <50% | 65%+ | 80%+ |
| **Completion rate** (reach last slide) | <60% (algo stops re-serving) | 70%+ | 80%+ |
| Active dwell time per slide | <2 sec | 3-5 sec | 6+ sec |
| Save rate (carousel-specific) | <0.8% | 1.5%+ | 3%+ |
| Send rate (carousel-specific) | <0.5% | 1%+ | 2%+ |

**Strategic implications**:
- Sweet spot = **5-8 slides** (or 8-10 max for deep content)
- **Slide 3 = «retention checkpoint»** — viewers who reach slide 3 have 80% likelihood to complete
- Place **strongest insight on slide 3**, not slide 1
- Last slide = CTA stack (Comment + Save + Send)

## 🧪 A/B Testing Protocol

### Frequency
1 test every **2 weeks**, ոչ ավելի հաճախ։ Faster = noise > signal։

### What to test (one variable at a time)
| Test type | A vs B example |
|-----------|----------------|
| Hook style | Question vs Statement |
| Hook category | Curiosity vs Nostalgia |
| CTA | Save vs Follow |
| Post format | Reel vs Carousel (same content) |
| Voice | Personal Maghakian vs Agency «մենք» |
| Posting time | 11:00 vs 19:00 (same day of week) |
| Caption length | <100 words vs 200+ words |
| First-frame hold | 0.5s vs 1.5s |

### Test rules
- Same content/topic, different variable
- Publish ~1 week apart on same weekday
- Compare metrics after 7 full days each
- Winner = clear lift (>20% improvement on primary metric)
- Inconclusive = run again

### Test log template
```
Test #: 001
Date: 2026-MM-DD
Variable: Hook style
A: Question hook
B: Statement hook
Same content: «Hotel Grand iconic line reveal»
Result A: 1.2% save rate
Result B: 2.4% save rate
Winner: B
Action: Apply to next 3 posts
```

## ⚔️ Kill / Double-Down Rules

### Kill Criteria (stop using this approach)
A post format/style/tactic = «kill» եթե.
- 3+ attempts at same approach
- All <50% of account average reach
- Save rate <0.3%
- No DMs / no comments

**Action**: Pause format for 60 days, then retest with refined hook.

### Double-Down Criteria (lean into this approach)
- 2x account average reach
- Save rate 2%+
- Share rate 1.5%+
- 5+ DMs from CTA

**Action**:
1. Publish 3 follow-ups in same format within 14 days
2. Pin top performer to profile
3. Create story highlight from it
4. Cross-post to TikTok / YouTube Shorts
5. Extract pattern → add to Maghakian Doctrine

## 📅 Review Cadence

### Daily (5 min, ոչ ավելի)
- Check last post's first-hour metrics
- Reply to all comments

### Weekly (30 min, every Sunday evening)
- Top 3 / bottom 3 posts of week
- Note format, tactic, hook category
- Update test log
- Plan kill/double-down for next week

### Monthly (90 min, first Sunday of month)
- Compare month over month: reach, follows, saves
- Identify top 5 tactics that worked
- Adjust calendar for next month based on data
- Refresh hashtag sets
- Audit bio + highlights

### Quarterly (3 hours, every 90 days)
- Strategic review: Are we hitting balanced goals (authority, followers, leads, reach)?
- Refresh content bank (add 30 new ideas)
- Audit underperforming patterns
- Consider tactical pivots
- Manifesto check: are we still authentic?

## 🚨 Alert Conditions

Set up self-alert (mental check or in spreadsheet) for.

### Negative alerts
- 3 consecutive posts below 1K reach → diagnose hook quality
- DM volume drops 50% → CTA is broken
- Follower growth -1% week → audit content alignment

### Positive alerts
- Single post 5x+ avg reach → analyze immediately, replicate within 7 days
- DM keyword «ՆԱԽԱԳԻԾ» spike → potential leads, manual outreach
- Story poll responses >100 → content hits a nerve, expand

Hold these constant; don't let weekly noise erode them.

## ⚠️ Anti-Patterns

❌ Daily obsessive metric checking (causes panic, not progress)
❌ Reacting to single post performance (need 3+ data points)
❌ Optimizing for vanity (likes, follower count alone)
❌ Comparing to non-comparable accounts (different niche, age, audience)
❌ Killing a tactic after 1 underperformer
❌ Doubling-down before signal is real (1 hit isn't trend)
❌ Changing strategy weekly (let signals stabilize)
❌ Hiding from bad metrics (look at them; learn)

## ✅ The 5-Question Weekly Audit

Every Sunday, ask:
1. Which post earned highest **save rate** this week? Why?
2. Which **DM keyword** got most replies? Is the offer working?
3. Did **bio + highlights** match this week's content theme?
4. Was there a **post I almost didn't publish** because of doubt — and how did it perform?
5. Am I closer to **Maghakian Manifesto** or further?

Answer honestly. Adjust.
