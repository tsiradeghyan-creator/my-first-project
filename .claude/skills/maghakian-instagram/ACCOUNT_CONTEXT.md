## 🧬 Hidden Pattern Analysis

### Pattern 1: Top performers are emotional/identity hooks, not project announcements
- «Քանի՞ տարեկան» = nostalgia + identity question
- «Ո՞վ է իրականում» = curiosity gap + character mystery
- «Կան պատմություններ» = emotional curiosity
- Project name in title alone ≠ viral

### Pattern 2: 88x amplification ceiling
- 989 followers → 87.2K top reel = 88x ratio
- Algorithm trusts this account when emotional triggers are present
- Massive untapped reach when hook quality stays consistent

### Pattern 3: Save/share ratio
- Save rate ≈ 0.9% (target 1-3%) → save-optimization is the #1 lift opportunity
- Share rate ≈ 1.0% (healthy)
- Comments-per-view highest on hooks that question viewer identity, not on info posts

### Pattern 4: Reach-to-follower leak
- 52K reach / 989 followers = vast asymmetry
- Hooks reach but profile doesn't convert
- **Root cause hypothesis**: bio doesn't sell, no consistent follow CTA, highlights not curated
