# ALGORITHM_2026.md – Instagram Algorithm Update (2026 Mechanics)

Skill-ի founding files-ը գրվել են generic algorithm understanding-ով։ 2026-ին Instagram-ի ranking signals **fundamentally shifted**։ Այս ֆայլը overrides հին assumptions-ները։

## 🔴 The 7 Critical Changes (2026)

### 1. **DM Sends = #1 ranking signal for Reels**
> «Send-arad to-friend (DM)» հիմա **highest-weighted distribution signal է**, ոչ saves, ոչ comments։

**Implication for @maghakianscripts**:
- Ամեն reel-ի **caption-ում պետք է share-incentive լինի**, ոչ միայն save
- Կոնկրետ CTA. «Ուղարկիր ընկերոջդ, ով Մանեի կողմում էր»
- Update CTA_LIBRARY priority՝ Share > Save > Comment > Follow

### 2. **Keywords > Hashtags for discovery**
> Հիմա Instagram-ը կարդում է **caption-ի և profile-ի բառերը SEO-style**։ Hashtags-ը կորցրեցին discovery-power-ի մեծ մասը։

**Implication**:
- Caption-ի առաջին 125 նիշերում **search-relevant keywords** (օր. «հայկական սերիալ», «scriptwriter», «Շանթ», «Maghakian», «Անի Մաղաքյան», project name)
- Profile NAME field (ոչ username) = searchable — հոս լրացնել keywords
- Hashtags still helpful, but **secondary**

### 3. **Hashtags no longer support follows**
> Մարդիկ չեն կարող hashtag-ով follow անել. discovery-only։

**Implication**: HASHTAGS.md priorities-ը պետք է թարմացվեն (շեշտը niche reach, ոչ tribe-building)։

### 4. **Originality Score** (NEW)
> Algorithm-ը identify է անում recycled content, watermarks, repurposed clips → ranking suppression։

**Forbidden moves (zero tolerance)**:
- TikTok watermark cross-post → **massive ranking penalty**
- CapCut watermark
- Same text-on-image template overused
- Stock footage without transformation

**Solutions**:
- Always export from TikTok WITHOUT watermark (use SnapTik, etc.)
- Re-edit before cross-platform posting
- Maghakian aesthetic = automatic originality (no one else has lamp-lit script aesthetic)

### 5. **3-Second Hook Rule (refined from generic "first second")**
> First **3 seconds** are decisive — 50%+ of viewers decide whether to keep watching by sec 3, not sec 1.

**Implication for REELS_EDITING.md**:
- Hook = visual + text + audio simultaneously in **0-3 sec window**
- Old «0.5 sec» rule = still true for absolute scroll-stop, but full **3 sec must deliver promise**

### 6. **First-Hour Comment Reply = Ranking Signal**
> Algorithm explicitly tracks creator's first-hour comment-reply rate. Ignoring = lost signal.

**Implication**:
- Schedule posts when you can reply for next 60 minutes
- Replies should ask follow-up question (extends conversation thread)
- Pinned comment = highest-engagement reply gets boost

### 7. **Optimal Content Mix (Instagram's own recommendation)**
- **3-4 reels** per week
- **2-3 carousels** per week
- **1-2 static posts** per week
- **= 6-9 feed posts** per week (matches CONTENT_CALENDAR.md 7-day cycle)

## 🟡 Algorithm Strategy Implications

### Reels-First Strategy (2026 priority)
Reels = primary distribution channel. Carousels = secondary (high engagement, but lower reach ceiling)։ Static = community-only։

### The 3-2-1 Rule for Reel Quality
- **3 seconds**: deliver visual + verbal hook
- **2 seconds**: between cuts (max retention)
- **1 CTA**: per reel, last 3 sec

### Cross-Reach Tactics (2026-friendly)
- **Comment-to-DM** automation (covered in DM_RESPONSES.md)
- **Carousel Reels** (NEW format: image carousel that auto-plays like reel) — **10% engagement vs 6% for regular reels**
- **Trial Reels** (covered in TRIAL_REELS.md)
- **Broadcast Channel** posts (covered in BROADCAST_CHANNEL.md)
