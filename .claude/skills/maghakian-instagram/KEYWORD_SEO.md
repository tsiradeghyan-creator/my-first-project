# KEYWORD_SEO.md – SEO-Style Content Optimization

🔄 **Paradigm shift (2026)**: Instagram-ը հիմա կարդում է **caption-ի և profile-ի բառերը SEO-style**։ Hashtags-ը կորցրին discovery-power-ի մեծ մասը։ Skill-ի HASHTAGS.md-ը դառնում է **secondary**, KEYWORD_SEO.md-ը` **primary**։

## 🎯 The Shift

| Before 2026 | After 2026 |
|-------------|-------------|
| Hashtags = discovery king | Keywords = discovery king |
| Bio = personality | Bio = SEO + personality |
| Caption = engagement only | Caption = engagement + searchable keywords |
| Profile name = personal | Profile name = searchable keyword phrase |

## 🔑 The 4 SEO Surfaces

### 1. Profile **NAME** field (not username — the bold display name)

**Bad** (low-discovery): «Maghakian Scripts»
**Good** (SEO-optimized):
```
Maghakian Scripts | Հայ սցենարիստ
```
Or even tighter:
```
Անի Մաղաքյան | Հայ սցենարիստ • Шант • 47 серии
```

Searchable keywords loaded:
- «Հայ սցենարիստ» (Armenian scriptwriter)
- «Շանթ»
- Founder name «Անի Մաղաքյան»

### 2. Bio Description

First 100 chars matter most (display priority on profile).

**SEO-optimized bio**:
```
Հայկական սցենարային գործակալություն
Ելենի օրագիրը • Hotel Grand • Բեկորներ • Երկուսով
47 նախագիծ • 198 մաս • 80,000+ էջ
↓ Behind the scripts ↓
```

Keywords loaded:
- «Հայկական սցենարային գործակալություն»
- Project names (each = searchable)
- Numbers (people search «47 series Armenian»)

### 3. Caption First 125 Characters

This is the «preview» that Instagram cuts at։ Stuff your keywords here.

**Bad** (low-SEO): «Բարի լույս բոլորին, այսօր ուզում եմ պատմել մի սցենարի մասին»

**Good** (SEO-loaded):
```
«Երկուսով» սերիալի կերպարների մասին — Մանե, Մարկ, Լիլի, Սամվել — հայ scriptwriter-ի perspective-ից։
```

(First 125 chars contains: project name, all character names, niche, role identity)

### 4. Reel / Carousel On-Screen Text

Instagram OCR reads text on images/videos։ Hook text = SEO signal too.

**Bad**: «Watch this →»
**Good**: «Հայ սերիալների ամենահայտնի plot twist-ը»

## 📝 Keyword Integration Rules

### Caption structure (recommended)

```
[1-2 line: SEO keywords loaded — first 125 chars]
[3-5 lines: emotional hook / story (engagement)]
[1 line: CTA]
[hashtags]
```

### Examples

**Good caption opening** (SEO + hook combined):
```
«Հատուկ դասարան»-ի (Շանթ TV) finale-ն ինձ ստիպեց վերաշինել ողջ scriptwriting մեթոդս։
2,264 սերիա ավելի ուշ, ահա ինչ սովորեցի...
```
(SEO content: project name + channel + niche + numbers + niche reiteration. Hook content: «ստիպեց վերաշինել» = curiosity gap)

## 🚫 Anti-Patterns

❌ Keyword-stuffing without flow («հայ սերիալ scriptwriter Armenia drama serial...»)
❌ Generic words («great», «amazing», «awesome» = zero discovery value)
❌ Only English keywords (loses Armenian discovery)
❌ Only Armenian (loses diaspora)
❌ Bio with all emojis, no text
❌ Caption hiding keywords below «...more» fold (first 125 chars wasted)

## 🧪 Test Plan

A/B test over 2 weeks:
- **Week 1**: Caption Format A — keyword-front-loaded
- **Week 2**: Caption Format B — emotion-front-loaded, keywords mid-caption

Measure: profile visits, reach to non-followers, discovery surface impressions

Expected: A wins on reach, B wins on engagement։ Hybrid likely best.
