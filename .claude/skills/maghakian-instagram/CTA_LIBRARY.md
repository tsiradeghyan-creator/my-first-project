# CTA_LIBRARY.md – Call-to-Action Arsenal (60+ CTAs)

CTA-ն որոշում է, թե post-ից հետո ինչ տեղի կունենա։ Generic «Like and follow»-ը մահացած է։ Specific CTA-ը 3-5x ավելի effective է։

## Մատենագիր
- Կանոններ
- 10 կատեգորիա × 5-7 CTA = 60+
- Decision matrix՝ ո՞ր CTA-ն ո՞ր post-ին
- Pairing rules (CTA-ները կարող են քիչ թվով combine լինել)

---

## 🧭 5 Rules of CTAs

1. **Մեկ CTA / post** – երկու CTA-ն կորցնում է երկուսն էլ
2. **Specific over generic** – «Save՝ որ վաղ առավոտյան վերադառնաս» > «Save this»
3. **Reward, not demand** – հանդիսատեսին տուր reason, ոչ command
4. **Match goal** – save CTA save-ի համար, follow CTA follow-ի համար
5. **Test, don't assume** – 2 շաբաթը մեկ test 2 CTA style

## 🎯 CTA Decision Matrix

| Post goal | Primary CTA | Backup CTA |
|-----------|-------------|------------|
| Top-of-funnel reach | Comment bait (3) | Share (2) |
| Algorithm boost | Save (1) | Comment (3) |
| Build community | Share (2) | DM trigger (5) |
| Grow followers | Follow (4) | Profile visit (6) |
| Generate leads | DM trigger (5) | Action (10) |
| Recurring traffic | Engagement loop (7) | Follow (4) |
| Sales / partnership | Action (10) | DM trigger (5) |
| Audience research | Poll/Quiz (8) | Comment (3) |

---

## 🔗 Pairing Rules

### ✅ Allowed pairs (max 2 CTAs)
- Save + Follow (passive duo)
- Share + Comment (engagement duo)
- DM trigger + Follow (lead + retention)

### ❌ Don't pair
- Multiple action CTAs (split attention)
- Save + Save variant (redundant)
- Comment + Comment variant
- Follow + Profile visit (same intent)

---

## 🚫 Anti-Pattern CTAs

❌ «Like if you agree»
❌ «Double-tap if relatable»
❌ «Follow for more» (generic, no value prop)
❌ «Tag friends» (no reason given)
❌ «Comment below» (no specific prompt)
❌ «Check link in bio» (no incentive)
❌ «Don't forget to like and follow» (begging)
