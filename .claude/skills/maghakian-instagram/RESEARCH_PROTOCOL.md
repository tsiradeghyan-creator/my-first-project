# RESEARCH_PROTOCOL.md – Pre-Copy Research & Verification

🔒 **Կանոն #0**: Երբեք մի՛ հորինիր կոնկրետ բան իրական Maghakian project-ի մասին։ Հանդիսատեսը հիշում է scene-ները, character-ները, line-ները։ Մեկ false claim → trust collapse → save rate և follower retention dropdown 50%+։

Այս ֆայլը ապահովում է, որ ամեն copy generation-ից առաջ research գրավված է, gap-ները լրացված են user-ի կողմից, և fabrication-ները նշված են որպես այդպիսին։

---

## 🎯 When to Run Protocol

**ՊԱՐՏԱԴԻՐ** երբ որևէ task ներառում է.
- Կոնկրետ project-ի անուն (Ելենի օրագիրը, Hotel Grand, Երկուսով, և այլն)
- «Iconic line / phrase» reveal
- «Deleted scene» reference
- Character monologue / backstory
- Cast tag / actor reference
- Premiere date / season info
- BTS «թե ինչպես գրվեց» story
- Cross-project Easter egg

**Չի պահանջվում** երբ.
- Pure scriptwriting tip / education (no specific show reference)
- Generic industry commentary
- Personal Maghakian diary (about feeling, not facts)
- Account-level milestone (47, 80,000, 9 տարի — verified facts)
- Universal post idea (no project name)

---

## 📋 The 6-Step Protocol

### Step 1 — Status Check

Հարցրու ինքդ քեզ.
- Project-ը արդեն եթեր ե՞լ է (completed/aired) → կա research material
- Upcoming-ն է → research-ը սահմանափակ, ուղիղ user-ի մոտ
- Unknown status → հարցրու user-ին

**Output**: `[Project Name] – Status: aired / upcoming / unknown`

---

### Step 2 — Web Research (եթե aired)

Օգտագործիր **WebSearch** tool-ը։ Multi-language queries.

#### Query templates
```
"[project name]" սերիալ
"[project name]" Shant
"[project name]" հայ սերիալ դերակատարներ
"[project name]" Maghakian
"[project name]" Armenian series cast
"[project name]" հայ սերիալ ՅՈՒթուբ
site:shant.am "[project name]"
site:armenianseries.com "[project name]"
site:wikipedia.org "[project name]" Armenian
"[project name]" русский армянский сериал
```

#### Priority sources (best signal-to-noise)
1. **Shant.am / shanttv.am** – original production source
2. **Wikipedia** (Armenian + English + Russian variants)
3. **IMDB** – cast confirmation
4. **YouTube** – clip titles reveal iconic moments
5. **1in.am, ArmenPress, Yerevan.today, NEWS.am** – Armenian press
6. **fanblogs / Telegram channels** – fan commentary reveals iconic lines
7. **@maghakianscripts own past posts** – check the user's archive first
8. **Instagram cast handles** – via search results

#### Extract these 7 data points
- ☐ Plot premise (1-2 sentences)
- ☐ Main characters' names (2-3 minimum)
- ☐ Cast (lead actors, full names + IG handles if available)
- ☐ Premiere year + season count
- ☐ Channel / production company
- ☐ Genre + mood
- ☐ At least 1 iconic moment / scene / line that fans reference

---

### Step 3 — Sufficiency Gate

Count ☐ from Step 2.

| Filled | Action |
|--------|--------|
| 7 / 7 | ✅ Full data – proceed to copy generation |
| 5-6 / 7 | ⚠️ Proceed but flag missing in output as «assumption» |
| 0-4 / 7 | ❌ STOP – go to Step 4 (ask user) |

**Important**: «Cast handles» missing → can proceed without tagging, but flag it։
«Iconic moment» missing → MUST go to Step 4 if intending Tactic 2/3/4 reveals.

---

### Step 4 — Ask User (Targeted Gaps)

Օգտագործիր **AskUserQuestion** tool։

#### Rules
- Maximum **4 հարց** (ոչ ավելի – user fatigue)
- Միայն **gap-ները**, ոչ ամեն ինչ
- Specific, ոչ generic («Ինչ կա ճամպրուկի մեջ» > «Պատմիր ինձ plot-ը»)
- Options provide (multiple choice > open text – user-ի համար արագ)

#### Standard gap questions (pick relevant)

**Plot / character gaps**:
> «Ի՞նչ key plot point / scene կուզե՞ս center stage»
> Options: [scene A], [scene B], [character arc], [Other]

**Iconic line gap**:
> «Ի՞նչ phrase / line «[project]»-ից հանդիսատեսը հիշում է»
> Options: [if research found candidates] / "ինքս կասեմ" / "չկա հատուկ" / "Other"

**Deleted content gap**:
> «Կա՞ իրական deleted scene կամ cut content, որ կարող ենք reference անել»
> Options: «Այո, ունեմ արխիվում» / «Այո, բայց պետք է գտնեմ» / «Չկա» / «Կարող եմ նոր գրել»

**Cast / tag gap**:
> «Որ actor-ի handle-ները tag-ենք»
> Options: [list candidate handles from research] / «Բոլորին» / «Միայն lead-ին» / «Չտագնել»

**BTS story gap**:
> «Կա՞ իրական behind-the-scenes պատմություն, որ կարող ենք կիսել»
> Options: [list known stories from research] / «Կիսեմ DM-ով» / «Չկա/չեմ կիսում» / «Hypothetical-ով գնանք»

**Lead magnet gap** (եթե DM funnel):
> «"ՃԱՄՊՐՈՒԿ" (or any DM keyword) DM-ի դիմաց ի՞նչ ենք ուղարկում»
> Options: «Ունեմ original PDF» / «Պետք է գրենք» / «Փոխիր offer-ը» / «Չանենք DM funnel»

---

### Step 5 — Provenance Verification (Pre-Write)

Մինչ copy գրելը, ամեն potentially fabricable claim-ի համար ստուգիր.

| Claim type | Source needed |
|-----------|----------------|
| Iconic line quote | User OR research-confirmed |
| Character name | User OR research-confirmed |
| Cast member | Research-confirmed (IMDB/IG) |
| Premiere date | Research-confirmed |
| Channel | Research-confirmed |
| BTS specific story | User-confirmed |
| Deleted scene detail | User-confirmed |
| Cross-project connection | User-confirmed |

#### Acceptable invention markers (when no real info exists)
Կարող ես **հորինել**, բայց **հստակ markup-ով**.

- «Եթե [character] ճշմարտությունը գիտեր...» (hypothetical confession – clearly framed as «if»)
- «Պատկերացրու scene, որտեղ...» (imaginary scenario marker)
- «Writers' room-ի hypothetical fork...» (alt-history marker)
- «Հանդիսատեսի մի՛ խումբ ենթադրեց, թե...» (referencing audience speculation, not internal fact)

#### NOT acceptable (forbidden fabrications)
- «4 rewrite, 1 producer veto» (specific false numbers)
- «6 ժամ writers' room վիճեցինք X line-ի շուրջ» (specific false event)
- «Մի մանրուք բերեցինք [unspecified project]-ից» (false cross-reference)
- «Producer-ը ուզում էր կտրել» (false attribution)

---

### Step 6 — Document Output Provenance

Output-ի վերջում միշտ ավելացրու.

```
📚 Research sources used:
- [url 1]
- [url 2]
- [user-provided info]

✅ Verified facts:
- [list]

❓ User-provided clarifications:
- [list]

⚠️ Hypothetical / unverified markers used:
- "if [character] knew..."
- [other]

🚫 No specific BTS / deleted scene / iconic line was fabricated.
```

## 🚦 Decision Tree Summary

```
START
  ↓
Does task reference real project?
  ├─ NO → Skip protocol, proceed normally
  └─ YES ↓
       ↓
    Project status?
       ├─ Unknown → Ask user
       ├─ Upcoming → Skip Step 2, go to Step 4
       └─ Aired ↓
            ↓
         WebSearch (Step 2)
            ↓
         Sufficiency Gate (Step 3)
            ├─ 7/7 → Step 5
            ├─ 5-6/7 → Step 5 with flags
            └─ <5/7 → Step 4 (Ask User) → Step 5
                 ↓
              Step 5 (Verify provenance)
                 ↓
              Step 6 (Document in output)
                 ↓
              GENERATE COPY
```

## 🧪 Example: «Երկուսով» Protocol Run

### Step 1 — Status
@maghakianscripts archive հղում: project #5 from 47-list → **aired**

### Step 2 — Web Research queries
- `"Երկուսով" սերիալ Shant`
- `"Երկուսով" հայ սերիալ դերակատարներ`
- `"Erkusov" Armenian series cast`
- `site:shant.am Երկուսով`

### Step 3 — Sufficiency
Hypothetical research output:
- ☐ Plot premise: ✅ (love triangle, choosing between 2 men)
- ☐ Characters: ⚠️ (need names)
- ☐ Cast: ⚠️ (need actors)
- ☐ Year: ⚠️
- ☐ Channel: ✅ (Shant from logo)
- ☐ Genre: ✅ (drama)
- ☐ Iconic moment: ❌

Score: 3/7 → **STOP, ask user (Step 4)**

### Step 4 — Targeted questions
> Q1: Ի՞նչ էր իրականում scene-ում ճամպրուկի մեջ
> Q2: Ի՞նչ iconic line «Երկուսով»-ից հանդիսատեսը հիշում է
> Q3: Ո՞ր actor-ների handles-ը tag-ենք
> Q4: Կա՞ deleted scene / BTS, որ կիսելու ենք DM-ով

### Step 5 — Provenance check before each line of copy
- «մորս նամակները» ← user-ից կամ research-ից։ Եթե ոչ → hypothetical-ով marker.
- Iconic line ← user-ից։ Եթե ոչ → ոչ Tactic 2։
- «Writers' room-ում 6 ժամ վիճեցինք» ← FALSE if not provided by user. REMOVE.

### Step 6 — Document
```
📚 Research: [WebSearch results listed]
✅ Verified: Shant Production, drama, 2-man triangle
❓ User-provided: [whatever user gave]
⚠️ Hypothetical: «Հարսի մասին գրելը հեշտ է» (framed as writer's reflection, not project fact)
🚫 No invented plot specifics.
```

## 🎯 Edge Cases

### Case A: Project is too obscure (no web results)
- Skip Step 2, go to Step 4 directly
- Tell user: «Չգտա ինտերնետում մանրամասներ։ Կարո՞ղ ես կիսել plot-ը»

### Case B: User wants speed, doesn't want questions
- Use ONLY hypothetical markers throughout
- No specific claims about plot, characters, lines
- Lean on Tactics 6 (Industry Pullback), 7 (Numbers), 12 (Personal Diary) – which don't require project specifics
- Tactic 2, 3, 4, 11 are OFF-LIMITS without verified info

### Case C: Conflicting info between research and user
- User's word > research (they made the show)
- Note conflict in output's provenance section

### Case D: Project is the user's own account brand (Maghakian Scripts itself)
- Numbers, year, project count, agency story → verified from ACCOUNT_CONTEXT.md, no further research needed
- Personal Maghakian voice → use freely (it's the user's voice)

---

## ⚠️ Anti-Patterns

❌ Հորինել detail և հույս դնել, որ user-ը կնկատի
❌ Skip protocol-ը «արագ» անելու համար
❌ Ask user >4 հարց (overload)
❌ Generic հարց («Պատմիր ինձ project-ի մասին») – not actionable
❌ Search միայն մեկ language-ով – Armenian + Russian + English crucial
❌ Forget Documentation (Step 6) – հանդիսատեսը ընթացքից դուրս է, բայց user-ը պետք է իմանա ինչ verified է

## ✅ Protocol Compliance Check

Մինչ copy-ի delivery-ն, ստուգիր.

- ☐ Web research run? (եթե aired project)
- ☐ Sufficiency ≥5/7 OR user-clarified gaps?
- ☐ Every specific claim has source?
- ☐ Hypothetical markers used where appropriate?
- ☐ Documentation block included in output?

Բոլորը ✅ → publish-ready copy։
Որևէ ❌ → STOP, rework։
