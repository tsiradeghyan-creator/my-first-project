# Անի Մաղաքյան — Սցենարական Պորտֆոլիո

> Maghakian Script Writing Agency-ի հիմնադիր և սցենարիստ Անի Մաղաքյանի ամբողջական ֆիլմագրությունը։
> Օգտագործիր այս տվյալները ցանկացած պորտֆոլիոյի, bio-ի, press kit-ի, սոցիալական փոստի, pitch-ի կամ կրեդիտի դեպքում — որ թվերը ճշգրիտ լինեն և ոչ մի նախագիծ բաց չմնա։

## Հաշվարկի մեթոդաբանություն

- **1 սերիա = ~35 էջ սցենար**
- **ֆիլմ / ներկայացում = ~40–60 էջ**
- **«Պտպտիկ մտմտիկ» (մանկական կոնտենտ) = ~60 էջ**
- **«Էլենի օրագիրը»** հաշվված է 197 սերիա, **«Էլենի օրագիրը 2»**՝ 224 սերիա — որ ընդհանուր 421-ը կրկնակի չհաշվվի։

## Ընդհանուր հաշվարկ

| Կատեգորիա | Ծավալ |
|---|---|
| Սերիալային / մասանոց նախագծեր | **2,264–2,273 սերիա / մաս** |
| Միայն սերիալների սցենարային էջեր | **79,240–79,555 էջ** |
| Ֆիլմեր + ներկայացումներ + «Պտպտիկ մտմտիկ» | **220–300 էջ** |
| **Ընդհանուր սցենարային նյութ** | **≈ 79,460–79,855 էջ** |

Բացի սցենարներից՝ Անի Մաղաքյանն ունի նաև **700+ լրագրողական հոդված**։

## Փոստի / պորտֆոլիոյի ֆորմուլացիաներ

- Կարճ՝ **«Մոտ 80,000 էջ սցենարային աշխատանք»**
- Պրեմիում՝ **«80,000 էջից ավելի պատմություններ, կերպարներ ու դրամատուրգիա»**
- Թվային հենք՝ **«46 նախագիծ · 2,200+ սերիա · ~80,000 էջ · 2017–2026»**

## Կիրառման կանոններ

- Պորտֆոլիոյի կամ ձեռքբերումների մասին գրելիս **երբեք մի վկայակոչիր միայն «84-ի ամառը»-ն** կամ որևէ առանձին նախագիծ որպես ամբողջ ստեղծագործական ուղին — օգտագործիր ընդհանուր թվերը։
- Թվերը մոտավոր են (հաշվարկված վերը նշված մեթոդաբանությամբ) — փոստերում օգտագործիր «մոտ», «ավելի քան», «≈» ձևակերպումներ, ոչ թե բացարձակ ճշգրիտ թիվ։
- Հատուկ նախագիծ նշելիս՝ վերցրու անունն ու տարին ուղիղ այս աղյուսակից (ուղղագրությունը՝ ճշգրիտ)։
- Ժանրը՝ հիմնականում մելոդրամա/դրամա, ընտանեկան սերիալ, մանկական կոնտենտ, վերջին տարիներին նաև թատերական պիեսներ և ֆիլմեր։
