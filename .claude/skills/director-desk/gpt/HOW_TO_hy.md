# Maghakian Script Desk · ChatGPT-ի համար

Այս փաթեթով ChatGPT-ն անում է նույնը, ինչ Claude-ը.
- Անիի սցենարը (KIT-ի Word ֆայլ) ֆորմատավորում է «ամերիկյանկայով»՝ PDF Maghakian լոգոյով, Word, Final Draft;
- սրբագրում է՝ կետադրություն, ուղղագրություն, տառասխալներ, իմաստային և շարունակականության սխալներ;
- տալիս է **աշխատանքային Word** (ամեն ուղղում դեղինով, ամեն մեկի կողքին մեկնաբանություն՝ ինչու) և
  **վերջնական PDF** սցենարիստների, պրոդյուսերների համար;
- breakdown՝ էջեր, րոպեներ, լոկացիաներ, կերպարներ, ներս/դուրս, սեզոնի ամփոփում։

## Մեկ անգամ՝ սարքել GPT-ն (5 րոպե)
1. chatgpt.com → ձախում **GPTs** → **Create** → վերևում **Configure**։
2. **Name:** `Maghakian Script Desk`։ **Description:** `Սցենարի ֆորմատ, սրբագրում, breakdown`։
3. **Instructions:** բացիր `INSTRUCTIONS.md` ֆայլը, ամբողջը պատճենիր և տեղադրիր այս դաշտում։
4. **Knowledge → Upload files:** բեռնիր `knowledge/` թղթապանակի **բոլոր** ֆայլերը (12 ֆայլ)։
5. **Capabilities:** միացրու **Code Interpreter & Data Analysis** (պարտադիր)։ Web Search-ը պետք չէ։
6. **Create** → «Only me» (սցենարները գաղտնի են)։
   Լոգոն որպես GPT-ի նկար՝ վերևի շրջանակի վրա սեղմիր և բեռնիր `knowledge/maghakian_logo_dark.png`-ը։

Եթե Custom GPT սարքել չես ուզում՝ սովորական չատում բեռնիր `knowledge/` բոլոր ֆայլերը + սցենարը,
և առաջին հաղորդագրությամբ տեղադրիր `INSTRUCTIONS.md`-ի տեքստը։

## Ինչպես օգտվել
Բեռնիր սցենարը (KIT-ից արտահանված .docx, կարելի է մի քանի սերիա) և գրիր, օրինակ.
- «Ֆորմատավորիր ամերիկյանկայով, սերիալը՝ 84-ի ամառը»
- «Սրբագրիր 1-ին սերիան. տուր աշխատանքային Word-ը և վերջնական PDF-ը»
- «Սարքիր սեզոնի breakdown 5 սերիայի համար»

Ստանալու ես.
| Ֆայլ | Ում համար |
|---|---|
| `ep01_WORK.docx` | Անիին. դեղին՝ փոխված, փիրուզագույն՝ հարց/դիտողություն, աջում՝ մեկնաբանություններ։ Word-ում Review → Comments |
| `ep01_FINAL.pdf` | Ալիքին, հարթակին, նկարահանող խմբին. մաքուր, լոգոյով |
| `ep01_FINAL.docx`, `.fdx` | Մաքուր տեքստ Word-ով և Final Draft/KIT-ի համար |
| `ep01_corrections.md` | Բոլոր ուղղումների աղյուսակը + ավտոմատ ստուգումներ |

## Կարևոր
- ChatGPT-ն երկար սցենարի դեպքում երբեմն կանգնում է կիսատ. եթե ասում է «ստուգեցի 10 տեսարան», գրիր
  «շարունակիր մինչև վերջ»։ Պահանջիր, որ ասի քանի տեսարան է ստուգել 31-ից։
- Երկխոսության խոսակցական ձևերը («էկար», «ա», «էսա») **չպետք է ուղղի**՝ դա կերպարի ձայնն է։ Եթե ուղղում է՝
  ասա «երկխոսության ոճը մի փոխիր, միայն տառասխալ և կետադրություն»։
- Վերջնական PDF-ը ուղարկիր միայն Անիի հաստատումից հետո (աշխատանքային Word-ով)։
- Եթե Code Interpreter-ը սխալ է տալիս, գրիր «սկզբից պատճենիր ֆայլերը /mnt/data/desk և նորից փորձիր»։

Claude-ում (Claude Code) նույն գործը անում է `director-desk` սքիլը. ասա «սրբագրիր սցենարը»։
