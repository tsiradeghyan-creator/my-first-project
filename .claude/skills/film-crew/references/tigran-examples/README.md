# Prompts Tigran brings as a quality bar

Tigran shares prompts he likes so the crew learns from them. Each file holds one prompt **verbatim**, then a short analysis:
- what to take;
- what to leave;
- what our skills already do.

Read these before writing a performance-driven video prompt. Copy the techniques, not the text.
