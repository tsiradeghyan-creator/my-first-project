# Style lens library

This is a **cache, not a limit**: any director, cinematographer, editor or film can be the lens — missing ones are
researched from real sources (`film-style-researcher` in Claude Code, web search elsewhere) with `_template.md` and
saved here as `researched-unreviewed` until the user approves. One lens per film. Every department applies it.
Prompts carry the translated craft, never the name.
