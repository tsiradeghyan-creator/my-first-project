# Higgsfield Motion Presets

This is the concise entrypoint. The older full playbook is preserved in `references/full-guide.md` and must be loaded only when this skill is actually routed.

## Required Reference

- `references/full-guide.md`

## Operating Contract

- Read `references/full-guide.md` before naming or recommending presets.
- Use exact preset names from the reference or verified platform data.
- Pair presets with clear subject, timing, camera, and safety constraints.
- Verify current preset availability when the user plans to spend credits or use the UI immediately.

## Output Contract

- Recommended preset or short preset shortlist.
- A paste-ready prompt line showing how to apply it.
- Any safety, IP, likeness, or platform-availability caveat.

## Verification

- Confirm the preset name appears in the reference or current platform data.
- Check that the preset matches the user's genre and source material.
- Flag high-risk face/body transformations and suggest safer wording when needed.

## Safety Boundaries

- Get explicit approval before spending credits, publishing, uploading private media, or changing account/platform state.
- Do not use private likeness, voice, protected identity, or rights-sensitive material without clear authorization.
- Do not delete, overwrite, or move user files unless explicitly asked.
- Treat model names, platform features, prices, schedules, and public claims as time-sensitive.
